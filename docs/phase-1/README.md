# Phase-I and FYDP Thesis Figures

This directory contains all PNG figures referenced by:

- `docs/phase-1-progress-report.md` (FYDP Phase-I progress report)
- `docs/fydp-thesis.md` (FYDP final thesis report)

The figures are copied from `docs/latex/figures/` (the conference paper) and
`docs/thesis/figures/` (the LaTeX thesis) so the user can paste them into
the Google Docs version of the report without hunting through the
repository.

## How to paste in Google Docs

In the Google Docs version of the report, drag the PNG file from this
folder into the indicated `[Figure X: ...]` placeholder in the markdown.
The figure replaces the placeholder text. Keep the original caption from
the markdown.
